\section{What the Current Artifact Supports}

At HoloScript commit
\texttt{eae6d1113814d3e284807f4e6ceae92f68a860f8},
\texttt{CAELRecorder} appends a canonical hash-linked JSONL event stream.
\texttt{CAELReplayer} reconstructs a contracted solver and re-executes recorded
\texttt{step} and \texttt{solve} events.  Interaction records are decoded and
re-logged; their actions, world mutations, cognition effects, perception
effects, and CRDT updates are not applied during replay.

The default chain checksum is FNV-1a.  SHA-256 can be selected, but neither mode
by itself authenticates origin.  Same-adapter state-digest comparison is
conditional on two matching non-empty adapter fingerprints and retained digest
arrays.  The wire projection is schema agreement; it omits solver fields, state
digests, and final physics outcomes and therefore does not prove cross-adapter
physics determinism.

A dated reporter in the canonical paper repository records all selected tests
passing.  This is implementation coverage, not evidence for the withdrawn
semantic or performance claims.

\section{Promotion Gates}

A future results supplement requires:
\begin{enumerate}
  \item versioned executable interaction commands with explicit apply
        semantics;
  \item fail-closed adapter identity and domain-complete state oracles;
  \item a state-changing action and solve through the production TET10
        adapter;
  \item content-addressed CRDT updates and independent replica replay;
  \item branch-prefix and branch-final equality with mutation negative
        controls;
  \item per-step GPU spike capture and a separately scoped parity study; and
  \item raw structured receipts for every reported trial, latency, memory, and
        overhead value.
\end{enumerate}

Until those gates pass, this file documents exclusions only and must not be
packaged as empirical supplemental material.

## Findings

1. `REQUIRE_2FA` was the only clear narrow cleanup candidate. It guarded Tier-2
   self-custody export and custodial wallet routes, but an unset env skipped 2FA
   even though the code warns that production should enable it. The route gate
   now defaults to requiring 2FA when `NODE_ENV=production` and `REQUIRE_2FA` is
   unset. Explicit `REQUIRE_2FA=false|0|no` remains an intentional override.

2. HoloKey/x402 custody flags are present and concrete. HoloScript has live
   HoloKey and x402 gates such as `HOLOKEY_DATABASE_URL`,
   `HOLOKEY_PROD_KEK_CURRENT`, `ALLOW_MOCK_X402`,
   `GIST_MANIFEST_REQUIRE_X402`, and `HOLOSCRIPT_WALLET_KEY`.
   ai-ecosystem has local custody/signing flags such as
   `HOLOMESH_REQUEST_SIGNING`, `HOLOMESH_RECEIPT_SIGNING`,
   `HOLOMESH_HTTP_ALLOW_UNSIGNED_FALLBACK`, `HOLOMESH_DISABLE_REQUEST_SIGNING`,
   and `ALLOW_MISSING_FOUNDER_CHECKPOINT`. No broad cleanup was safe without
   changing operator behavior; these are compatibility or local-run gates.

3. `ALLOW_MOCK_X402` in ai-ecosystem is not a live env toggle. It appears in the
   historical `hooks/data/ratchet-marathon-2026-05-28` task material that
   documented the original overclaim and remediation path. The live HoloScript
   `ALLOW_MOCK_X402` path is fail-closed and returns `no_x402_facilitator`
   unless explicitly set for development.

4. No HoloGate or Corridor env key appeared in the focused flag inventory.
   HoloGate remains an umbrella/docs semantics issue, not proof of a runtime
   feature flag. The existing board follow-up
   `task_1783063651680_cq5a` covers the Paper 35 HoloGate umbrella terminology
   reconciliation; this A-011 pass did not file a duplicate.

5. HoloKey, umbrella routing, and triad/uAAL integration are already covered by
   concrete ai-ecosystem audit surfaces: `scripts/audit-holoscript-tool-integration.mjs`,
   `scripts/workspace-drift-tracker.mjs`, `scripts/task-tier-router.mjs`, and
   `config/task-tier-router.json`. Those are not feature flags, so this cleanup
   pass treats them as neighboring substrate checks rather than env-toggle debt.

% ── Abstract ─────────────────────────────────────────────────────────────────
\begin{abstract}
Shared spatial worlds that admit both human users and autonomous agents face a
fundamental trust gap: existing co-presence protocols treat every participant
identically, conflating the unbounded action space of an agent with the
intent-bounded behavior expected at a spatial threshold.  The result is either
over-restriction (agents cannot act) or under-restriction (agents can mutate
shared state without auditability).

We present \hg{}, a spatial co-presence system in which every portal crossing is
governed by content-negotiated scope ladders, A2A agent-card handshakes, and an
audit receipt chain that ties world-state hashes to provenance across entry,
mutation, and exit.  \hg{} uses Loro CRDT as its conflict-free state substrate,
WebRTC as its delta transport, and HoloScript \texttt{.hsplus} policies as its
scope enforcement layer.  An intent validator gate rejects out-of-scope actions
at
\measuredFrom{scripts/receipts/hologate-portal-bench-receipt.json}%
772\,ns average latency (1.3\,M validations/sec), while portal threshold
negotiation adds only
\measuredFrom{scripts/receipts/hologate-portal-bench-receipt.json}%
1.6\,µs average overhead (p99: 4.0\,µs) per crossing.  Delta broadcast to 50
subscribers costs
\measuredFrom{scripts/receipts/hologate-portal-bench-receipt.json}%
2.2\,µs per event; world-state SHA-256 over 1\,K entities completes in
\measuredFrom{scripts/receipts/hologate-portal-bench-receipt.json}%
2.0\,ms.  Two-agent Loro CRDT convergence under concurrent writes stays below
\measuredFrom{scripts/benchmarks/hologate-crdt-convergence.json}%
10\,ms round-trip, and the harness scales to
\measuredFrom{scripts/benchmarks/hologate-scale-20.json}%
20 concurrent entrants with 32/32 adversarial tests passing.  Scope violation
rejection is verified across a 34-test matrix covering scope$\times$intent
product, \texttt{allowedScopes} gate, glob specificity, and warn mode; audit
receipt chain integrity is verified across 8 tests covering chain-link
correctness, canonical hash, rewind provenance, and multi-agent isolation.

\hg{} contributes: (1)~a content-negotiated portal protocol that binds
capability to spatial context; (2)~a scope-ladder policy model with glob
specificity and incremental trust elevation; (3)~a world-state audit receipt
chain enabling tamper-evident rewind; and (4)~an open-source implementation
in TypeScript with 91+ tests across 8 modules.
\end{abstract}

% ── §1 Introduction ──────────────────────────────────────────────────────────
\section{Introduction}
\label{sec:intro}

Spatial shared worlds are the next multi-agent coordination layer.
Avatar-based virtual environments, XR co-working spaces, and simulation
sandboxes already host both human users and autonomous agents.  Yet the
admission protocol at every spatial boundary---what \hg{} calls a
\emph{portal threshold}---is almost universally identity-only: a bearer token
or session cookie authenticates the participant, but carries no binding on what
the participant is \emph{allowed to do inside}.

This creates an unbounded action-space problem.  An agent that has been admitted
through a portal can in principle mutate any shared state that its session
credentials allow.  This is too broad for human co-presence contexts (users
expect bounded, predictable agent behavior) and too narrow for agent-only
contexts (agents need the ability to express capability bids and negotiate
scope).

We identify three missing primitives:
\begin{enumerate}
\item \textbf{Content-negotiated scope.}  The portal threshold should be a
  two-party protocol in which the agent presents a capability card and the
  world replies with an admitted scope ladder, not a binary allow/deny.
\item \textbf{Conflict-free state.}  Multiple agents and humans writing
  concurrently to shared world state need a convergence guarantee, not a
  last-write-wins merge that silently drops updates.
\item \textbf{Audit receipts.}  Every entry, mutation, and exit should
  produce a hash-chain receipt that allows tamper detection and exact rewind
  to any prior world state.
\end{enumerate}

\hg{} provides all three.  The system is built on HoloScript \texttt{.hsplus}
policy contracts (scope enforcement), the Loro CRDT library (conflict-free
state), WebRTC (delta transport), and a world-state SHA-256 receipt chain.
The A2A agent-card handshake protocol draws on the agent identity layer
described in~\cite{paper29algebraictrust} \todo{confirm cite key};
the CRDT state model is compatible with the spatial CRDT architecture
of~\cite{paper32crdtspatial} \todo{confirm cite key}; the pillar-slice
token compression of HoloGate intent tokens relates
to~\cite{paper26latenttoken} \todo{confirm cite key}.

\paragraph{Contributions.}
\begin{enumerate}
\item \textsc{HoloPortal}: a content-negotiated portal protocol in which agents
  present A2A agent cards and receive scope-ladder admissions
  (\S\ref{sec:portal}).
\item \textsc{HoloDoor}: a policy enforcement gate that validates intents
  against admitted scopes using glob specificity ranking and warn/deny modes
  (\S\ref{sec:scope}).
\item A world-state audit receipt chain that hashes per-entity state at every
  mutation boundary and supports deterministic rewind (\S\ref{sec:receipts}).
\item An evaluation showing sub-microsecond intent validation, sub-2-µs
  threshold negotiation, Loro CRDT convergence below 10\,ms, and correct
  behavior under 34 scope-violation and 8 receipt-chain adversarial tests
  (\S\ref{sec:eval}).
\end{enumerate}

\subsection{HoloPortal: Content-Negotiated Portal Protocol}
\label{sec:portal}

A \emph{portal} is a typed spatial boundary with an admission policy
expressed in a \texttt{.hsplus} contract.  When an agent (or human session)
requests entry, the portal initiates a two-phase threshold negotiation:

\begin{enumerate}
\item \textbf{Capability presentation.}  The entrant presents an A2A agent
  card listing its claimed capability set.  \todo{TypeScript listing: agent
  card structure + bid envelope from holo-portal-intent.ts}
\item \textbf{Scope grant.}  The portal policy evaluates the bid against the
  world's trust policy and returns an admitted scope ladder.  Scope entries
  use glob patterns; specificity ranking determines which entry wins when
  multiple patterns match.
\end{enumerate}

Threshold negotiation is encoded in the \texttt{portal-entry.v1} receipt
format, extending the \texttt{holotunnel.share-packet.v1} receipt schema
(commit~\texttt{b2da5af09}).

The \texttt{@portalPresence} trait (\texttt{af2b2a18e}) exposes the portal
protocol to any HoloScript entity, making co-presence a first-class trait
rather than a hard-wired runtime hook.

\subsection{HoloDoor: Scope-Ladder Policy Enforcement}
\label{sec:scope}

\todo{Expand: allowedScopes gate, glob specificity algorithm, warn vs deny
modes, integration with holoscript-mcp-custody-contract.hsplus.}

\hd{} intercepts every intent emitted by an admitted participant and validates
it against the scope ladder granted at entry.  Validation is purely
in-process; no round-trip to an external policy service.

Scope matching uses a three-tier specificity ranking: (1)~exact path match,
(2)~single-segment glob, (3)~multi-segment glob.  Conflicts are resolved by
most-specific wins.  An intent that matches no scope entry is rejected in
\texttt{deny} mode or flagged in \texttt{warn} mode.

\subsection{Loro CRDT State Layer}
\label{sec:crdt}

Shared world state is stored in a Loro tree container.  Each entity occupies
a node; properties are Loro map entries.  Concurrent writes from multiple
participants converge deterministically (commit \texttt{af53937c1}: Loro CRDT
replaces prior LWW deepMerge).  Delta encoding of Loro changesets is the unit
of WebRTC broadcast (commit~\texttt{3e82a2eb5}).

\subsection{Audit Receipt Chain}
\label{sec:receipts}

At every mutation boundary the world-state SHA-256 is computed over all entity
properties in canonical JSON order (commit~\texttt{2b973eaaf}).  The hash is
appended to a receipt chain; each link records:
\begin{itemize}
\item mutation type (entry/field-write/exit),
\item agent identity (from A2A card),
\item admitted scope at time of mutation,
\item SHA-256 of state before and after,
\item ISO-8601 timestamp.
\end{itemize}

Rewind restores any prior state by replaying the chain to the target link.
Multi-agent receipt isolation ensures that concurrent participants produce
non-interfering receipt sub-chains that merge via Loro without aliasing.

\section{Discussion}
\label{sec:discussion}

\subsection{Threat Model and Limitations}
\label{sec:threats}

\paragraph{Malicious scope inflation.}
An agent that obtains a broader scope than its card warrants can violate
world policies silently.  The current model trusts the portal policy to
evaluate bids correctly but does not enforce cryptographic binding between
the card and the bid.  Future work: extend A2A cards with hardware-attested
signatures (compatible with the EIP-712 anchor layer described
in~\cite{eip712anchor2026} \todo{confirm cite key}).

\paragraph{Receipt chain forgery.}
SHA-256 is collision-resistant but not authenticated: a malicious participant
with write access to the receipt store can substitute a fabricated chain.
The current model stores receipts in process memory; production deployment
should anchor chain roots to an external immutable log (e.g., the Base
mainnet anchor used by the broader HoloScript provenance system).

\paragraph{CRDT divergence under network partition.}
Loro's CRDT guarantees convergence only after all deltas are delivered.
Under indefinite partition, local state diverges.  The current model has no
partition-detection or explicit merge-conflict surfacing for human users.

\paragraph{Scale ceiling.}
The 20-entrant benchmark is the largest validated harness.
\todo{Characterize expected scaling behavior as N grows; does broadcast cost
grow linearly with subscriber count or does the 50-subscriber micro-bench
represent the real fan-out bound?}

\paragraph{Quest 3 validation.}
The evaluation is browser-native (TypeScript/WebGPU).  Quest 3 headset
validation is an open gate: the QuestProofPanel
(\texttt{packages/studio/src/components/quest/QuestProofPanel.tsx},
commit~\texttt{cbe4e77f3}) is ready but no device receipt has been recorded
in \texttt{.bench-logs/} at time of writing.

% ── §7 Conclusion ────────────────────────────────────────────────────────────
\section{Conclusion}
\label{sec:conclusion}

\hg{} demonstrates that spatial portal crossings can carry first-class
capability negotiation without imposing overhead on the hot path.
Intent validation at \measuredFrom{scripts/receipts/hologate-portal-bench-receipt.json}772\,ns
and threshold negotiation at \measuredFrom{scripts/receipts/hologate-portal-bench-receipt.json}1.6\,µs
average leave ample budget for game-loop and simulation-loop integration.
The Loro CRDT substrate provides convergence guarantees that LWW merges
cannot, and the audit receipt chain enables tamper detection and deterministic
rewind at world-state granularity.

Together, these contributions reduce agent+human co-presence from a binary
identity-admit problem to a structured capability negotiation, provably auditable
after the fact.

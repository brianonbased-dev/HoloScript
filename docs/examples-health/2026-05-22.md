### 1. Unquoted composition names now rejected

Parser requires `composition "Name" {` (quoted string).

```

```

Affects: most `emotion/`, `lighting/`, `weather/` examples.

### 2. Arrow event handler syntax removed

```

on eventIdentifier(param) { ... }         // PASS (entity level)
```

### 3. Traits inside `light {}` blocks rejected

`@animated { ... }` inside `light "Name" { ... }` is invalid. Use `animate: { ... }` property instead.

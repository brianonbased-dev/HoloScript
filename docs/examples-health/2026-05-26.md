## Phase 1 — Parse Failures (26 total)

All failures are parser drift — the HoloScript grammar has evolved and these examples use
syntax patterns that the current parser no longer accepts.

### Error Pattern A: `Expected COLON, got LBRACE` — in `domain-postfx` blocks (10 files)

Parser now requires a colon after a domain identifier before its body block.
Before: `domain-postfx { ... }` → After: `domain-postfx: { ... }` (or restructured).

### Error Pattern B: `Expected string, got IDENTIFIER` — entity names (5 files)

Entity names inside `composition {}` now require string quotes.
Before: `entity VolumeKnob { ... }` → After: `entity "VolumeKnob" { ... }` (or `object "VolumeKnob"`).

Affected files:

### Error Pattern C: `Expected identifier, got AT` — `@trait` in domain blocks (2 files)

`@trait` directives are not valid inside `domain-*` sub-blocks;
they must be at object or composition level.

Affected files:

- `examples/audio/spatial-audio-showcase.holo`
- `examples/audio/spatial-audio-showcase.refreshed.holo`

### Error Pattern D: `Unexpected token: DOT` — property dot-access in `.hs` (2 files)

is now rejected. Property path access syntax may have changed.

Affected files:

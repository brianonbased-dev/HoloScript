### P2 — Security

#### P2-001 · TLS certificate validation disabled for external PostgreSQL connections

**Commit:** `12596009`
**File:** `packages/marketplace-api/src/PostgresSkillDatabase.ts:84`

```typescript
const isPrivate = connectionString.includes('.railway.internal');
this.pool = new Pool({
  connectionString,
  ssl: isPrivate ? false : { rejectUnauthorized: false },
});
```

`rejectUnauthorized: false` bypasses TLS certificate verification for any connection string that does not contain `.railway.internal` (e.g. local dev using `DATABASE_URL=postgres://...public.railway.app/...`, CI, or any future non-Railway deployment). An attacker who can intercept the connection (MITM on the CI runner, a misconfigured network hop, or a future cloud migration) can present a forged certificate and capture DB credentials and all marketplace skill data.

**Fix options (ascending preference):**

1. Short-term: document in env setup that `DATABASE_URL` must always be the `.railway.internal` private URL in production, so this branch is unreachable.
2. Better: pass Railway's CA cert via `ssl: { ca: process.env.PGSSLROOTCERT }` for external paths.
3. Best: remove the `rejectUnauthorized: false` path entirely; reject startup if the connection string is not on the private domain and no CA cert is configured.

### P3 — Code Quality / Minor

#### P3-001 · TOCTOU race on `initialized` flag in `PostgresSkillDatabase.getClient()`

**Commit:** `12596009`
**File:** `packages/marketplace-api/src/PostgresSkillDatabase.ts:95-108`

```typescript
private async getClient(): Promise<PoolClient> {
  if (!this.initialized) {
    await this.initSchema();   // ← two concurrent requests both enter here
  }
  return this.pool.connect();
}
```

Two concurrent requests that arrive before `this.initialized` is set will both call `initSchema()`. The SQL uses `CREATE TABLE IF NOT EXISTS` and `CREATE INDEX IF NOT EXISTS`, so the double-run is idempotent and harmless in practice. However, a Promise-based single-init idiom is safer and avoids the redundant round-trips:

```typescript
private initPromise: Promise<void> | null = null;
private async ensureInit(): Promise<void> {
  if (!this.initPromise) this.initPromise = this.initSchema();
  return this.initPromise;
}
```

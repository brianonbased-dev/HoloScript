# HoloScript Systems Toolchain `0.1.0` readiness baseline

Date: 2026-07-22<br>
Disposition: **PUBLISHED OUTWARD PREVIEW**<br>
Scope: first outward preview under the
[native machine release ladder](../spec/native-machine-release-ladder.md).

The `holoscript-systems-toolchain` distribution presents HoloScript as a general-purpose semantic
systems programming language: a pinned CLI and language core, the `hs-machine-v32` native compiler,
and a portable WASM parser/type-checker. Hosted MCP, Absorb, and Studio remain optional,
independently versioned companions. PyPI is excluded from this first distribution identity.

The machine-readable authority is
[`systems-preview-release-manifest.json`](../../scripts/holo-ci/systems-preview-release-manifest.json),
and the consumer boundary is defined in the
[`0.1.0` distribution contract](0.1.0-distribution-contract.md). All required gates passed before
publication; public npm and GitHub readback now pass as well.

## Consumer proof

Fresh temporary projects installed both the exact local tarball and the public
`@holoscript/systems@0.1.0` package without repository access. The probes verified:

- package identity and public-registry integrity;
- exact dependencies `@holoscript/core@8.0.17` and `@holoscript/cli@8.0.11`;
- the `holoscript`, `hs`, and `holoscriptc` command surfaces;
- parse and validation of all 25 corpus programs through the packed WASM runtime; and
- native compilation and execution of all 25 programs, each returning the declared exit code 5.

The exact npm, native, and WASM artifacts passed allowlist and secret-shaped-material scans. No
founder-local path, credential, private key, wallet material, auth cache, or unintended source map
was detected.

## Next release transition

Treat `0.1.0` as immutable. Any correction receives `0.1.1` or later with fresh deterministic,
conformance, cold-consumer, registry, and cross-rail receipts. The next preview minor must publish
migration notes for every changed language, CLI, manifest, or ABI boundary; stable `1.0.0` remains
a separately admitted public contract.

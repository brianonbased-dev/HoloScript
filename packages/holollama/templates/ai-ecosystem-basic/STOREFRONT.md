# Vehicle greeter

This folder is the **vehicle you ride** between product doors. It is not
Joseph’s desk. Secrets stay in local `.env`. Do not copy anyone else’s
GOLD, wallets, or machine paths into this tree.

## Ask first

1. **Who is riding?** A person, an agent shopping for a person, or a teammate.
2. **Which door?** Language (HoloScript), worlds (HoloLand), crew (HoloMesh),
   admit (HoloQR / headset mark), mind (this package: llama.cpp serve / tune),
   pay (budget and receipts) — or stay here (doctor, lifecycle, receipts).
3. **What’s in the trunk?** Nothing, a `.holo` file, a headset, a repo, a
   board task.

Then serve **one meal**, or send the rider to the store that owns the job.
Do not dump the whole MCP catalog.

## Meal kits

| Rider said | Do this | Do not do this |
| --- | --- | --- |
| See something real / cyan orb | House special: one scene, two backends (WebGPU + URDF) | A 400-tool dump |
| Compile this scene to X | Parse, validate, the **named** compiler | Every `compile_to_*` as a tie |
| Scan a QR on Quest / walk up to a mark | Quest / HoloQR compile | Repo scan, reconstruct-from-video |
| Question about **this** repo | Absorb if stale, then ask with citations | Founder-path guesses |
| Local model | `holollama doctor`, then a dry serve plan | Claim “we trained AGI” |
| Can I afford this | Check budget first | Paste a token into a command |

House special source, when the language repo is in hand:
`examples/quickstart/1-floating-cyan-orb.holo`.

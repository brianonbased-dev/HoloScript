# Welcome to HoloScript! 🎉

HoloScript is a **general-purpose semantic systems programming language** designed for humans and AI agents to program applications, services, runtimes, simulations, devices, agents, and spatial worlds. This walkthrough begins with the spatial surface because it gives immediate visual feedback.

## What You Can Build

- 🎮 **VR Games** - Interactive worlds with physics, multiplayer, and haptics
- 🏢 **Enterprise XR** - Training simulations, data visualization, digital twins
- 🎨 **3D Art** - Generative installations, interactive galleries
- 🤖 **AI Agents** - Spatial computing with Claude, GPT, and custom models
- ⚙️ **Systems and Services** - Headless programs, policies, pipelines, runtimes, and device workflows

## Three File Formats

| Format    | Purpose                          |
| --------- | -------------------------------- |
| `.holo`   | Whole-system compositions and target orchestration |
| `.hsplus` | Typed behavior, traits, agents, state, and effects   |
| `.hs`     | Logic and process programs; pipelines are the strongest current lane |
